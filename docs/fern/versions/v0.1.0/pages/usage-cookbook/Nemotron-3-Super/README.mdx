A collection of notebooks demonstrating deployment and fine-tuning cookbooks for **NVIDIA Nemotron-3-Super**.

## Overview

These notebooks provide end-to-end recipes for deploying and customizing Nemotron-3-Super.

## What’s Inside

### Deployment

- **<Download src="../../../../../../../../usage-cookbook/Nemotron-3-Super/vllm_cookbook.ipynb"><Button intent="primary">vllm_cookbook.ipynb</Button></Download>** — Deploy Nemotron-3-Super with vLLM.

- **<Download src="../../../../../../../../usage-cookbook/Nemotron-3-Super/sglang_cookbook.ipynb"><Button intent="primary">sglang_cookbook.ipynb</Button></Download>** — Deploy Nemotron-3-Super with SGLang.

- **<Download src="../../../../../../../../usage-cookbook/Nemotron-3-Super/trtllm_cookbook.ipynb"><Button intent="primary">trtllm_cookbook.ipynb</Button></Download>** — Deploy Nemotron-3-Super with TensorRT-LLM.

- **[AdvancedDeploymentGuide](/usage-cookbook/nemotron-3-super/advanceddeploymentguide/readme)** — Production deployment configurations for vLLM, SGLang, and TRT-LLM across GPU topologies (GB200, B200, DGX Spark), including MTP speculative decoding, expert parallelism, and tuning guidance.

### Fine-Tuning

- **[grpo-dapo](/usage-cookbook/nemotron-3-super/grpo-dapo/readme)** — Full-weight RL training with GRPO/DAPO algorithm, reproducing emergent math reasoning from a base model.

- **[lora-text2sql](/usage-cookbook/nemotron-3-super/lora-text2sql/readme)** — Supervised fine-tuning (LoRA) recipe for the Text2SQL use case, including dataset preparation and training with [NeMo Megatron-Bridge](https://github.com/NVIDIA-NeMo/Megatron-Bridge) and [NeMo AutoModel](https://github.com/NVIDIA-NeMo/Automodel) libraries.

### Agentic

- **[OpenScaffoldingResources](/usage-cookbook/nemotron-3-super/openscaffoldingresources/readme)** — Guides for using Nemotron-3-Super with agentic coding tools (OpenCode, OpenClaw, Kilo Code CLI, OpenHands) via OpenRouter and build.nvidia.com.
